How We Verify Cost & Paywall Disclosures

In commercial software directories, apps often advertise themselves as "Free" because the app download itself costs ₹0, only for users to discover during exam revision that core features (such as scheduled app blocking or website limits) require an expensive monthly subscription.

ReflectHub's Rule: Any tool that requires payment for essential blocking, scheduling, or analytics features is classified as Freemium, and the exact paywalled tier is documented above. Only tools with 100% unrestricted core capability are labeled Free.
