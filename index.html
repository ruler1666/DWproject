Our methodology

How this hub was made

Unlike commercial review sites funded by affiliate links, ReflectHub was built as an academic digital wellness initiative. We ran focus sessions with engineering undergraduates, evaluated over 25 tools using consistent criteria, and documented every trade-off honestly.

Every tool was tested on physical budget hardware — Redmi/Snapdragon Android phones and standard Windows 10/11 laptops. Tools that lock essential features behind paywalls are labelled Freemium, never Free.
